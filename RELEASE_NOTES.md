# Versao 1.0.0

- Aplicativo nativo do Windows com interface simplificada.
- W automatico somente no ADC.
- Retorno para a loja aliada, espera de 10 segundos e recall quando o ADC morre.
- E automatico opcional a cada 25 segundos.
- F8 para pausar/retomar; comandos somente com o jogo em foco.

Baixe o ZIP e extraia todos os arquivos antes de abrir auto-yuumi.exe. Calibracao atual: 1920 x 1080. Alcance do W e interrupcao do recall nao sao detectados.
